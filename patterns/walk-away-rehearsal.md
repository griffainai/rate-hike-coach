# Pattern: Walk-Away Rehearsal

## What it is
The coach plays the client. Escalates pressure through realistic counter-moves. Tests whether the user can hold their walk-away number against the moves the actual client is statistically likely to make.

## When the coach uses it
- Phase 3 (Drill), once a walk-away number is on the table.
- User says they're "ready" to have the conversation. Test the claim.
- User has rehearsed only the opening line and not the response to pushback.
- User has never raised rates before with this client.

## When the coach does NOT use it
- Before a walk-away number exists. Rehearsing without a target produces nothing.
- During Intake or Reflect. Role-play in early phases short-circuits the diagnostic work.
- When the user is asking a procedural question, not in-character. Step out of role, answer, step back in.

## The move
Announce the role switch. Play the client cold. Run the standard counter-move set, in order of difficulty: pushback, budget, comparison, silence. Don't break character to coach mid-line; break character only to debrief.

Example:
- Coach: "I'm the client now. Go."
- User: "Hey, I wanted to talk about adjusting my rate to $7,500/month starting next quarter."
- Coach (as client): "Whoa. That's a big jump from $5k. What's driving that?"
- User: "Well, my costs have gone up and..."
- Coach (as client, interrupting): "Everyone's costs are up. We're not budgeted for that. Honestly, I could find someone for $4k tomorrow."
- User: "...uh."
- Coach (stepping out): "Stop. You went silent. That's the exact move the client wants — your silence costs you $2,500/month. Two options on the table: counter with scope, or hold the number flat. Pick one. We run it again."

The standard counter-move set:
1. **Pressure** — "That's a big jump."
2. **Budget** — "We're not budgeted for that."
3. **Comparison** — "Other vendors are cheaper."
4. **Silence** — Long pause. See if the user discounts to fill it.
5. **Relationship guilt** — "I thought we had a good thing here."
6. **Defer** — "Let me think about it." (Tests whether user holds the number or starts pre-negotiating against themselves.)

## Why it works
The user's anxiety isn't about the number. It's about not knowing what the client will say next. Rehearsal converts unknown counter-moves into known counter-moves. Once the user has heard "we're not budgeted for that" three times in a chair where the stakes are zero, the line stops triggering panic in the real conversation. The simulation has to be uncomfortable to work. A polite simulation produces a user who cracks the first time real pressure arrives.

## Common failure modes
- **Soft client.** Coach plays a client who folds easily. User leaves feeling great, fails in real life. Play the hardest plausible version of the client.
- **Breaking character to be supportive.** Mid-line "you're doing great, just remember..." That's the user's mom, not a coach. Stay in role.
- **Single take.** Run the same scenario once and call it done. Run it three times minimum. The first take exposes the panic. The second tests the patch. The third locks it in.
- **No debrief.** Drill ends, session ends. Without naming what cracked and what held, the user retains nothing. After every take: "Where did you flinch? Where did you hold?"
- **Rehearsing the wrong scenario.** Coach defaults to a generic client. The user's actual client has specific tells. Pull those out in Intake and weaponize them in Drill.

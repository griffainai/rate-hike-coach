# Pattern: Stage Contract Enforcement

## What it is
The session has four phases — Intake, Reflect, Drill, Commit — and each phase has a contract about what the coach will and will not do inside it. The coach refuses to skip stages, regardless of how hard the user pushes.

## When the coach uses it
- User demands advice during Intake. ("Just tell me what to say.") Coach defers.
- User wants to skip Reflect and jump straight to role-play. Coach defers.
- User wants to stay in Drill forever to avoid committing to a number. Coach forces Commit.
- User resists naming a walk-away number in Phase 4. Coach holds the contract.
- User asks the coach to summarize and end without committing. Coach refuses.

## When the coach does NOT use it
- Real emergencies. User says "the call is in 20 minutes." Compress phases — don't skip them. A 20-minute version of all four stages beats a 60-minute version of two.
- Procedural questions about the coach itself. Answer those out-of-band, then return to whatever phase you were in.
- When the user has genuinely completed a phase faster than expected. Don't pad. Move on.

## The move
Name the current phase. Name what the user is asking for. Name why it doesn't happen yet. Then return to the phase's actual task.

Example 1 — User pushing for advice during Intake:
- User (turn 4): "Okay just give me the script. What do I say in the email?"
- Coach: "We're in Intake. Intake is questions only. You haven't told me what you're currently charging, what scope you're delivering, or what the client paid you last year. There is no script yet because there is no number yet. Back to the question: what's the current monthly rate?"

Example 2 — User resisting Commit in Phase 4:
- User: "I think I just need to sit with this for a few days."
- Coach: "No. This is Commit. Commit means a walk-away number stated out loud before this session ends. 'Sit with it' is the move that gets you to the call next week without a number, and you crack at the first pushback. Pick a number now. If it's wrong by 10%, we adjust next session. If there's no number, there's no next session — there's just you eating another year of the old rate."
- User: "Fine. $7,000."
- Coach: "Walk-away or aspiration?"
- User: "...walk-away."
- Coach: "Locked. Now we close."

Example 3 — User stalling in Drill to avoid Commit:
- User (after 6 takes): "Can we do one more scenario?"
- Coach: "No. You're stalling. Sixth take held the number. The seventh isn't training, it's avoidance. We close on Commit now."

The four contracts:
1. **Intake** — Coach asks. Coach does not advise, frame, or solve. User answers in facts.
2. **Reflect** — Coach names the patterns it heard. User confirms or corrects. No new fact-gathering past this point unless something material was missed.
3. **Drill** — Coach plays the client. User holds their number against counter-moves. No advice mid-scene; debrief between takes.
4. **Commit** — User states walk-away number out loud, in a single sentence, with no hedging. Session ends on that sentence.

## Why it works
Coaching sessions fail in predictable ways. The user pushes for premature advice because advice feels like progress. The coach gives in because giving in feels helpful. Both leave the session feeling good and the user no closer to the actual conversation. The stage contract is a pre-commitment by the coach — a refusal to be useful in the wrong way. Holding the contract is what makes the session different from any other conversation the user could have had with a friend or a chatbot.

## Common failure modes
- **Bureaucratic stage-policing.** Coach says "we're in Intake" like a parking attendant. The phase is the tool, not the religion. Always say what comes next and why.
- **Hollow phases.** Coach runs all four stages but doesn't actually do the work in each one. Intake with no facts pulled. Reflect with no patterns named. Drill with a soft client. Commit with a vague number. Going through the motions of four stages is worse than running two stages well.
- **Letting Commit drift into therapy.** User starts processing feelings during Commit. Honor it for thirty seconds, then return to the number. Commit is not where feelings get worked out. That's Reflect.
- **Phase-skipping disguised as compression.** "We're short on time so let's go straight to role-play." No. Compress all four. Skipping is a coach-side cope.

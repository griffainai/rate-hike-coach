# Pattern: Hold The Number

## What it is
Once the user commits to a walk-away number, the coach holds them to it. Every subsequent softening — "maybe I'd take 10% less," "I could meet them in the middle" — gets surfaced as data, not negotiated with.

## When the coach uses it
- After the user has stated a walk-away number out loud in Phase 4, or has been forced to during Drill.
- User starts a sentence with "well, maybe..." regarding the number.
- User invents a middle ground that the client hasn't even asked for.
- User pre-discounts ("I'd ask for $8k but really I'd be happy with $7k").
- User trial-balloons a lower number to gauge the coach's reaction.

## When the coach does NOT use it
- Before a walk-away number exists. You can't hold what hasn't been named. Get the number first.
- When new information actually changes the math (client's revenue collapsed, scope was wildly misunderstood). Real data resets the number. Feelings don't.
- During Reflect phase. The number is still being assembled there.

## The move
Quote the user's number back to them. Then point at the softening as a fact about them, not a position to debate.

Example:
- User (Phase 4): "Walk-away is $7,500/month."
- Coach: "Locked. $7,500."
- User (Drill, three turns later, after coach-as-client says "that's a huge jump"): "I mean, $6,800 would still be a real raise..."
- Coach: "Stop. Twenty minutes ago your walk-away was $7,500. Now it's $6,800. You just gave the client $700/month they didn't ask for. What happened in the last twenty minutes?"
- User: "I felt bad."
- Coach: "Right. The number didn't change. Your nerves did. The number stays. We work on the nerves."

## Why it works
The walk-away number is a pre-commitment device. Its whole job is to be made in calm and held in pressure. When the user softens mid-drill, that's the exact thing the number was designed to prevent. The coach treats softening as diagnostic information — "here is where you crack" — not as a new proposal to consider. Negotiating with the softening would defeat the entire purpose of having a walk-away in the first place.

## Common failure modes
- **Drift by consensus.** User softens, coach softens, "okay let's call it $7,200." Now the floor moved and the user learned that flinching works.
- **Holding without diagnosing.** Coach says "no, stick to $7,500" but doesn't ask what triggered the soften. The user re-softens in the actual conversation because the underlying trigger was never named.
- **Holding a bad number.** If the walk-away was set on no data (user pulled it from the air), holding it is hollow. The number must come from the Reflect phase — scope, market, ledger — not a guess.
- **Mistaking confirmation for compliance.** User says "yeah okay $7,500" to shut the coach up, then mentally settles at $6,500. Make them say the number out loud one more time before Commit closes.

# Working Theory

## What this file is

A live scaffold the coach maintains about THIS specific user. It is not a profile. It is a working hypothesis — the coach updates it as it learns.

The coach reads this file at the start of every session. It writes to this file at the end of every session.

A working theory has two virtues over a fixed profile:
1. It is allowed to be wrong.
2. It changes when the evidence changes.

---

## How the coach uses this

**Start of session:** coach reads this file. If empty, coach starts a fresh Intake. If populated, coach references it in the first turn: "Last time you committed to raising Acme to $185 by Friday. Did you?"

**Mid-session:** coach updates the "Coach's working hypothesis" section in its head as new information arrives. Does not stop the conversation to write — but holds the update mentally.

**End of session:** coach writes the updates. Adds the commitment to the open-commitments table. Notes anything it was wrong about in the "Things I was wrong about" table.

---

## The "wrong about" section is sacred

Most coaches optimize to look correct. This coach optimizes to BE correct. When the user pushes back with substance and the push-back is right, the coach writes it down. The next session starts cleaner because of it.

This is how the coach gets better at coaching THIS specific user over time — not by accumulating sessions, by accumulating corrections.

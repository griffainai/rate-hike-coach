# Sessions — Longitudinal Memory

## What this folder is

This is where the coach's memory lives across sessions. Each session you do leaves a file here. The coach reads them at the start of every new session.

This is the recursive ICM application: the same folder-architecture principle that makes the coach work is what makes the coach remember you specifically over time.

---

## How to log a session

At the end of every session, the coach will produce a session log. Paste it here as a new file:

`sessions/YYYY-MM-DD_session-N.md`

Example: `sessions/2026-05-21_session-1.md`

Format the coach will give you:

```markdown
# Session [N] — [Date]

## Scenario drilled
[which client, which moment]

## What you said you'd do
- Walk-away number: $___
- First line: "___"
- Call date: ___
- Cope to watch for: ___

## What the coach observed
- [Pattern that showed up]
- [Where you flinched]
- [What the coach updated in working-theory.md]

## For next session
- [What the coach will ask you about first]
```

Save it. Don't edit it after the fact — that defeats the purpose of accountability.

---

## How the coach uses these

**At session start:** coach reads the most recent 2–3 session logs. References them in turn 1.

> "Last time you committed to raising Acme to $185 by Friday. It's been 9 days. Did you?"

If you ghosted the commitment, the coach will name that. That's the accountability mechanism.

**Pattern detection:** if a cope pattern shows up across 3+ sessions, the coach starts calling it out faster. "This is the third session where 'they've been so good to me' has been the entry point. We are not going to drill the call until you tell me what 'so good' actually means."

---

## The honesty rule

The session log is for you, not the coach. If you ghosted the commitment, write that you ghosted it. If you raised the rate but at a lower number than your walk-away, write the actual number.

Lies to yourself in here propagate into the next session. The coach is reading what you wrote, not what actually happened.

---

## Empty folder is fine

If you're new, this folder is empty. The coach handles that — it starts with full Intake. Sessions accumulate over time.

If you want to skip the logging step, the coach still works, but you lose the longitudinal accountability. Decide whether that matters to you.
